<h1 align="center">逗逼下载器 · DBDown</h1>

<p align="center">
  Kotlin / Jetpack Compose 原生 Android 下载器，支持 B 站、抖音、YouTube 和微博。<br />
  支持通过官方网页登录账号，默认选择当前可获取的最高画质与音质，也可手动更改视频规格及音轨。<br />
  支持视频、图集与实况图下载，自动识别分享链接和剪贴板内容，并提供下载进度、暂停与继续等管理功能。
</p>
