# 登录状态校验

应用启动、返回前台（五分钟缓存）、进入账号设置、网页登录完成以及解析下载资源前会异步校验。解析前强制刷新；并发请求合并。校验不阻塞匿名作品下载，下载接口的 B 站 -101 响应也会触发重新校验。

B 站使用官方 `/x/web-interface/nav` 的明确登录字段或 -101；抖音使用官方 `/passport/web/account/info/?aid=1128` 的会话过期响应。接口限流、风控、权限错误、非 JSON、超时与网络异常均不能据此认定登录失效，显示暂时无法验证。没有保存过凭据的用户显示未登录，不弹失效提示。

仅保存是否曾有凭据、是否已确认失效，不复制 Cookie。已经确认的失效状态跨进程保留；清除网页登录会同时清除此记录。网页登录过程中凭据改变时丢弃旧请求结果并重新校验。旧版安装在升级之前已经完全丢失的 Cookie 无法追溯，只能视为未登录。

失效提示提供忽略和前往设置。忽略仅抑制本次进程的重复提醒，设置页继续显示登录已失效。重新确认登录成功后清除失效状态；下次失效可以再次提醒。后台任务发现失效时记录状态，下次显示应用界面时展示对话框，不从后台强制拉起页面。

测试包含两平台认证/失效响应、风控和异常不误判，以及真机设置跳转、忽略去重与状态保留。真机测试仅修改无登录 Cookie 情况下的测试状态记录，恢复原记录，不改用户登录 Cookie。


抖音状态检查改用网页端 `/aweme/v1/web/user/profile/self/?aid=6383&device_platform=webapp`：`status_code=0` 且 `user.uid` 有效为已登录；`status_code=8` 为需要重新登录。其他错误或缺少身份字段为无法验证，不能仅凭 Cookie 存在认定有效。
