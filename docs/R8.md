# R8 发布构建

Release 已启用 `isMinifyEnabled`、`isShrinkResources`，使用 `proguard-android-optimize.txt` 和依赖库自带的 consumer rules。Debug 保持未压缩，方便调试。当前业务代码没有需要额外 keep 的反射入口；不要用全包 keep 或忽略所有警告来绕过构建问题。

每次发布须将 `app/build/outputs/mapping/release/mapping.txt` 与对应 APK 一起归档，后续构建会覆盖该文件。mapping 必须与实际发布的 APK 对应，用于还原混淆后的崩溃堆栈。

构建验证：`:app:assembleRelease :app:testDebugUnitTest :app:lintRelease`。还需安装最终签名的 Release APK 验证启动、旧下载记录、网页登录和更新入口；Debug 单测不能代替压缩版运行验证。
